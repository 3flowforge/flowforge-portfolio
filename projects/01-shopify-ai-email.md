# AI Email Support for Shopify Stores

**Problem:** A small store owner spends 1–2 hours a day answering "Where is my order?" and return questions.

**Solution:** n8n reads new support emails, looks up the order in Shopify, and Claude drafts a reply in the store's tone. Simple cases are labeled for one-click sending; complex ones are flagged for a human.

**Stack:** n8n · Gmail · Shopify Admin API · Claude API · Google Sheets (log)
